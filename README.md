## 1 Requerimentos ##
Es necesario tener instalado Node.js, se descarga desde la página web oficial. 
Para instalar los requerimentos necesario para la ejecución desde consola se usa el siguiente comando en powershell: 
    -pip install express ejs express-useragent

## 2 Ejecutar programa ##
Iniciamos npm (viene incluido con la instalación de node):
    -npm init -y

Inicializamos el servidor con el comando:
    -node server.js  

# Con esto instalado ya podemos ejecutar el programa en un servidor local desde un navegador e inspeccionar sus elementos #
